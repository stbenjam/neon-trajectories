# 64,067 Exclamation Marks

35 verbatim moments of unbridled excitement mined from 323 [Gemini 4 Neon (`xhigh`)](https://hub.harborframework.com/jobs/dc187a75-4c76-52ea-8616-eb89847d4542) trajectories on Terminal-Bench 4.1.

Live site: **https://bitbin.de/neon-trajectories/**

## Running Locally

Zero build step — pure HTML, CSS, vanilla JS, and local `Space Mono` / `IBM Plex Mono` fonts:

```bash
python3 -m http.server 8000
```

## Controls

- **Scroll** (or `↑` / `↓`, `j` / `k`) to move between quotes
- **Click any quote** (or press `Enter`) for full verbatim context and Harbor Hub trial link
- Press **`i`** (or click `index`) to browse and filter all 35 quotes
